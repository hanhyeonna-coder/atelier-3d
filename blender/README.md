# Blender pavilion generator

Blender 4.0.2에서 실행

1. Blender 실행
2. Scripting 워크스페이스
3. Text Editor > Open
4. atelier_pavilion_v1.py 선택
5. Run Script
6. 씬이 자동 생성되면 File > Save As로 .blend 저장

이번 버전은 공간 전용:
- 원형 파빌리온
- 바닥/기둥/유리돔
- 중앙 테이블
- 이젤 8개
- 덩어리 꽃 장식
- 잎사귀/컬러 포인트
- 조명/카메라

아바타는 다음 단계에서 별도 제작하는 게 맞습니다.

## 파일
- `atelier_pavilion_v1.py`: Blender 4.0.2에서 실행할 공간 생성 스크립트
